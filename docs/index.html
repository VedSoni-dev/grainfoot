What works

One file, any React site

GrainFooter.tsx needs nothing but React. Brand, three link columns, an images array, a status pill, socials, copyright and a credit line, all from one config object.

Adjustable grain

Built from SVG noise and CSS blend modes, not a baked image. Sliders for amount, size, weave and tint, plus an optional shimmer. Works on any photo.

Still or crossfading

One image stays still. Several crossfade on a timer and move on when you hover the band, with dots to pick one. Reduced motion is respected.

Plain HTML export

No React? Copy the style, markup and a 10-line script in one paste.

A playground

Add your photos or URLs, give each its path, drag the sliders, then copy your config, the component or the HTML. Everything stays in your browser.

Write the links with AI

Describe your site in a sentence and get a tagline and three link columns, through publik API or your own key.

Not yet

  • No npm package: copy the file instead.
  • No Vue or Svelte versions.
  • Only this footer layout so far.
  • Footers are saved in one browser only, with no sync between devices.

Run it yourself

git clone https://github.com/VedSoni-dev/grainfoot
cd grainfoot && npm install && npm run dev

The playground opens with Sign in with publik. The component itself needs no account.
